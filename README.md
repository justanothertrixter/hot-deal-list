# 🔥 HOT DEAL LIST — горячие предложения недвижимости Армении

Сервис по подписке: автоматически собирает объявления о продаже недвижимости с
[list.am](https://www.list.am) (Ереван и все регионы Армении), извлекает историю
изменения цен с каждой страницы объявления, находит те, у которых цена упала, и
показывает их подписчикам с фото, графиками и фильтрами.

## Тарифы

| План | Цена | Срок |
|------|------|------|
| 3 месяца (минимум) | **$201** (≈ $67/мес) | 90 дней |
| 6 месяцев | **$473** | 180 дней |

Годовой тариф пока не продаётся. Без подписки видны только первые 3 предложения
(превью), остальные скрыты за paywall. Оплата — в демо-режиме (платёжный шлюз не
подключён; на проде подключается Stripe, точка интеграции — `POST /api/subscribe`).

## Возможности

- **Карточки с фото** — изображения подтягиваются с list.am.
- **Цена за м² и её падение** — крупно на карточке (абсолютное падение и %).
- **Фильтры** — поиск по заголовку, тип недвижимости (квартиры/дома/земля/
  коммерческая/гаражи), регион, валюта, диапазон цены, минимальная скидка.
- **Мини-график** изменения цены (canvas) в каждой карточке.
- **Автообновление** — первый сбор при старте, затем каждые 6 часов (schedule).

## Технологии

- **Парсинг** — `curl_cffi` (имитация отпечатка Chrome) + `BeautifulSoup4`, без
  Selenium/Playwright. 1 запрос в 2–4 с (случайная задержка); при 403/429 —
  переключение отпечатка/User-Agent и рост задержки с последующим возвратом.
- **БД** — SQLite, файл `hot_deals.db`. Таблицы: `listings`, `price_history`,
  `meta`, `subscriptions`.
- **Backend** — Flask, один файл `app.py`.
- **Frontend** — чистый HTML + CSS + нативный JS (canvas), без фреймворков.

## Логика фильтрации сделок

Для объявления с историей цен:

- `drop_from_first = (first_price - current_price) / first_price`
- `drop_from_prev  = (previous_price - current_price) / previous_price`

Квалифицируется, если `drop_from_first >= 0.05` **или** `drop_from_prev >= 0.10`
(порог `0.05/0.10` максимизирует каталог — на текущих данных это 122 сделки).
Строгий порог `0.15/0.10` даёт 52 сделки; чтобы сузить выборку, используйте фильтр
**«Скидка ≥ %»** в интерфейсе. Гарантия ≥ 30 объявлений сохранена.

Планировщик каждые 6 часов запускает **глубокий** сбор (без раннего выхода), чтобы
каталог постоянно пополнялся.

## API

| Метод | Путь | Описание |
|-------|------|----------|
| GET | `/` | страница (hero, тарифы, фильтры, сетка) |
| GET | `/api/deals` | сделки (с фильтрами: `q`, `category`, `region`, `currency`, `min_price`, `max_price`, `min_drop`); без подписки — превью + `locked` |
| GET | `/api/filters` | доступные значения фильтров |
| GET | `/api/me` | текущая подписка |
| POST | `/api/subscribe` | оформить подписку `{plan: monthly|yearly, email}` (демо) |
| POST | `/api/cancel` | отменить подписку |
| POST | `/refresh` | запустить сбор вручную |
| GET | `/api/status` | статус сбора |

## Запуск

```bash
python3.12 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python app.py                      # http://127.0.0.1:5000
```

Служебные флаги:

```bash
python app.py --collect            # только сбор, без сервера
python app.py --backfill           # дозаполнить фото/тип у сделок
python app.py --port 8080          # другой порт
```

Секрет сессий: переменная окружения `HOTDEAL_SECRET` (по умолчанию dev-значение).

## Примечания

- Интерфейс list.am парсится на армянском (`/am/`), но селекторы не зависят от
  языка; даты разбираются на армянском/русском/английском, цены — в `$`/`֏`/`€`.
- Тип недвижимости берётся из breadcrumb страницы объявления (по ID категории),
  с fallback-эвристикой по заголовку.
- Цены сравниваются в рамках одной валюты. Фильтр по цене работает по числовому
  значению в валюте объявления (используйте фильтр валюты для корректного сравнения).
- Если после 50 распарсенных объявлений ни у одного нет истории цен, сбор
  останавливается с ошибкой (фрагмент HTML — в `structure_error.html`).

## Деплой на Render

Схема: **Render — витрина** (отдаёт сайт и API), **Mac — скрапер** (резидентный IP).

> list.am блокирует IP дата-центров, поэтому скрапер на Render не работает
> (`render.yaml` выставляет `HOTDEAL_DISABLE_SCHEDULER=1`). Каталог обновляется
> с вашего Mac, а Render передеплоивается при пуше.

1. **One-click деплой:** https://render.com/deploy?repo=https://github.com/justanothertrixter/hot-deal-list
   (Render читает `render.yaml`, free-план, `https://hot-deal-list.onrender.com`).
2. **Обновление каталога** — запускать на Mac:
   ```bash
   ./sync_render.sh
   ```
   Скрипт делает глубокий сбор, коммитит `hot_deals.db` и пушит в GitHub.
   Render (autoDeploy) передеплоивается с новыми данными.
3. По расписанию (cron, каждые 6 часов):
   ```
   0 */6 * * * cd /Users/hayk/Documents/deepseek-harness/default-workspace && ./sync_render.sh >> sync.log 2>&1
   ```

Для пуша без пароля настройте SSH-ключ GitHub или `git credential-osxkeychain`.
